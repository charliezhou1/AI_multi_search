Drag the teal-black button into your bookmarks bar. Prefer a manual setup? Use Copy Bookmarklet, then paste it as a new bookmark’s URL.

How it works

Everything runs in your browser on the page you already have open. No accounts, API keys, or backend.

1. Capture

Prefer highlighted text if you selected any. Otherwise, grab the latest user question from the ChatGPT page.

2. Choose

Pick Claude, Gemini, DeepSeek—or any combination—in a small on-page dialog.

3. Open & paste

Selected sites open in new tabs. Your question is copied to the clipboard. Claude may also get a URL prefill when that still works.

Supported platforms

Prefill is used only where it is currently reliable. Nothing is automatically submitted—you always review before sending.

Claude

Opens a new chat on claude.ai. When supported, the question is passed with a ?q= URL parameter so the composer can prefill.

URL prefill when available

Gemini

Opens gemini.google.com. Gemini does not offer a reliable public URL prefill, so paste from the clipboard.

Clipboard paste

DeepSeek

Opens chat.deepseek.com. No reliable native URL prefill—paste the copied question into the chat box.

Installation

Works best in desktop Chrome or Edge with the bookmarks bar visible.

  1. Show your bookmarks bar ((Chrome: View → Always Show Bookmarks Bar), or press Cmd/Ctrl + Shift + B.
  2. Drag the AI Multi-Search button above onto the bookmarks bar.
  3. Or click Copy Bookmarklet, create a new bookmark, and paste the code into the URL field. Name it “AI Multi-Search”.
  4. Open a conversation on chatgpt.com, then click the bookmarklet.
  5. If new tabs do not open, allow pop-ups for ChatGPT and try again.
Browser limits: Bookmarklets can only read the page you are on (same-origin). They cannot reach into other tabs. Multiple window.open calls may be blocked until you allow pop-ups. Prefer selecting text if ChatGPT’s layout changes and auto-detection misses your question.

Privacy

Designed to stay local. Your prompts are not sent to us.

  • No accounts, tracking pixels, or analytics in this project.
  • No backend and no API keys.
  • The bookmarklet does not use eval and does not fetch remote scripts.
  • Question text is read from the current page (or your selection), copied to your clipboard, and only sent onward when you open a destination site you choose.
  • Destination sites (Claude, Gemini, DeepSeek) have their own privacy policies once a tab opens there.
